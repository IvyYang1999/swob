04 · Trust

Local-first, with the network boundary stated plainly.

“Local-first” should describe architecture, not hide exceptions. Swob documents which operations stay local, which actions connect elsewhere, and what optional AI analysis samples.

LOCAL / 01

Core evidence stays on the Mac.

Browsing, SQLite indexing, search, lineage, graph layout, execution inspection, context analysis, audit, Quick Report, and export run locally.

NETWORK / 02

Optional actions are explicit.

Update checks contact the release service. Resume can open a terminal or configured SSH host. AI Report sends bounded real user-message samples only after confirmation.

CREDENTIALS / 03

Know the current limitation.

AI provider credentials are stored in the local Swob Library configuration and are not encrypted by Swob in current main.

AI sample boundary: up to 60 recent sessions, 8 user messages per session, 300 characters per message, and 120,000 sampled characters total. Read the full privacy document before enabling AI Insights.

06 · FAQ

Before you install.

The important limitations are part of the decision, not hidden below the download button.

Does v1.3.0 include the Session Galaxy and Debugger?

Yes. The signed v1.3.0 installers contain the released capabilities shown on this page.

Does every supported harness expose the same data?

No. Swob natively reads 6 harnesses (Claude Code, Codex, Cursor, OpenCode, Zcode, Pi), supports 1 compatible format (CC Mirror), and experimentally detects files from 4 more (Antigravity, Grok/Factory, Kimi, Hermes — file discovery only, content reading not yet implemented). Even among natively read sources, lineage, tokens, child agents, and resume commands depend on what each source records. Swob leaves unavailable fields unavailable.

Does session content ever leave my Mac?

Core browsing and analysis do not upload it. Optional AI Report sends bounded real user-message samples to the provider you configure after an explicit confirmation. Update checks and user-triggered SSH/resume actions can also use the network for their stated purpose.

Why does macOS say the app is damaged?

The old v1.2.0 DMGs were unsigned and can be blocked by Gatekeeper. v1.3.0 is signed and notarized, but v1.2.0 cannot safely auto-update across that trust-root boundary. Download the matching v1.3.0 DMG and overwrite Swob once.

Is Windows or Linux supported?

macOS is the current stable release. Windows x64 has a Native Alpha limited to Claude Code and Codex browsing, search, backup, Resume, and a minimal Library loop; it is not macOS feature parity. Linux and headless/browser mode are not current product claims.
