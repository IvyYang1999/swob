01 · 会话血统

02 · 调试器

别再猜会话为什么跑偏。

答案很少只是“模型不行”。Swob 让你检查会话背后的执行路径、上下文组成、压缩节点、工具错误、延迟、框架开销和证据质量。

04 · 信任

本地优先，也把联网边界讲清楚。

“本地优先”应该描述真实架构，而不是掩盖例外。Swob 明确说明哪些操作留在本地、哪些动作会联网，以及可选 AI 分析会采样什么。

本地 / 01

核心证据留在 Mac 上。

浏览、SQLite 索引、检索、血统重建、星图布局、执行检查、上下文分析、审计、Quick Report 与导出均在本地运行。

联网 / 02

可选联网动作明确可见。

更新检查会访问发布服务；续接可打开终端或已配置的 SSH 主机；AI Report 只会在确认后发送有严格上限的真实用户消息样本。

凭据 / 03

了解当前限制。

AI 服务商凭据保存在本地 Swob Library 配置中；当前 main 尚未由 Swob 加密这些凭据。

AI 采样边界：最多 60 个近期会话、每个会话 8 条用户消息、每条 300 个字符，采样总量不超过 120,000 个字符。启用 AI Insights 前，请阅读完整的隐私文档。

06 · 常见问题

安装之前，先把限制讲清楚。

重要限制本就应该参与决策，而不是藏在下载按钮下面。

v1.3.0 包含 Session Galaxy 会话星图和调试器吗？

包含。已签名的 v1.3.0 安装包具备本页展示的正式发布能力。

所有支持的来源都能提供同样的数据吗？

不能。Swob 原生读取 6 种 harness（Claude Code、Codex、Cursor、OpenCode、Zcode、Pi），支持 1 种兼容格式（CC Mirror），另有 4 种实验性文件检测（Antigravity、Grok/Factory、Kimi、Hermes——仅发现文件，尚不读取正文）。即使在原生读取的来源中，血统、token、子 Agent 和续接命令也取决于每种来源实际记录的内容。缺失的字段会保持不可用，不会被臆造补齐。

会话内容会离开我的 Mac 吗？

核心浏览与分析不会上传会话内容。可选的 AI Report 会在你明确确认后，把有严格上限的真实用户消息样本发送给你配置的服务商。更新检查与用户主动触发的 SSH／续接操作，也会为各自注明的目的使用网络。

为什么 macOS 提示应用已损坏？

旧 v1.2.0 DMG 未签名，可能被 Gatekeeper 阻止。v1.3.0 已签名并完成公证，但 v1.2.0 无法安全自动跨越新的信任根；请下载匹配架构的 v1.3.0 DMG 并覆盖安装一次。

支持 Windows 或 Linux 吗？

macOS 是当前稳定发布平台。Windows x64 有 Native Alpha，只验证 Claude Code 与 Codex 的浏览、搜索、备份、Resume 和最小 Library 闭环，并非 macOS 功能对等版。Linux 与无界面／浏览器模式仍不是当前产品承诺。
