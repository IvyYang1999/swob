// the problem

Your AI conversations have history.
Your tools pretend they don't.

  • Sessions scatter across ~/.claude/projects, ~/.codex/sessions, and more — no unified view, no search.
  • compact folds your early turns into a summary and hides the originals. You lose what you actually said.
  • resume creates a new file. fork branches off. Nobody tells you which session came from which.
  • Claude Code's default cleanupPeriodDays: 30 silently deletes old sessions from disk.
253 / 1,621
15.6% deleted by the official 30-day policy

From one real user's session history: 253 sessions had already been purged by Claude Code's default cleanup. They survived only because swob had backed them up. The official tool is deleting your conversations — and you might not even know.

// what swob does

Session lineage, not just session viewing.

Other viewers show you individual conversations. Swob shows you the relationships between them — fork edges, continuation chains, multi-file resumes — plus compact expansion and 5-platform unification.

  • Lineage detection

    Swob identifies fork, resume, and compact relationships between sessions, builds a lineage registry, and persists it across cache rebuilds. You see which session begat which — like git log --graph for your AI conversations.

  • Compact expansion

    Compacted turns are still in the JSONL. Swob surfaces every compact block inline and lets you expand each one in place — no manual file spelunking.

  • 5-platform unification

    Claude Code, Codex, Cursor, OpenCode, Zcode — one sidebar, one search, one resume button. Each session shows its source badge.

  • Full-text search + Spotlight jump

    ⌘K for cross-session full-text search (matches auto-expand compact segments). ⌘⇧K for fuzzy Spotlight-style jump filtered by content, project, time, or source.

  • One-click resume

    Resume any session in Terminal or iTerm2, preserving working directory and permission mode. Supports codex/cursor resume, batch resume, and SSH remote resume.

  • Token insights

    5 stat cards, 365-day contribution heatmap, source/model distribution, per-project token ranking, and 30-day trend — know where your tokens are going.

// cli

swob in your terminal

$ swob search "refactor database"
$ swob list --source claude-code --json
$ swob resume a6771e74
$ swob insights
$ swob install # installs Claude Code Skill

All commands output JSON. swob install adds a Claude Code Skill so Claude can query your session history mid-conversation.

// known limitations

Things you should know before installing

  • ROADMAP Tree visualization is not built yet. Swob detects lineage relationships (fork/resume/compact edges) and stores them in a registry, but does not yet render a visual tree graph. What you get today is relationship annotations and multi-file grouping — the visual tree is on the roadmap.
  • UNSIGNED The app is not code-signed. macOS Gatekeeper will block it. After downloading, run: xattr -cr /Applications/Swob.app
  • macOS ONLY Swob is an Electron app currently built and tested only for macOS. No Windows or Linux builds at this time.
