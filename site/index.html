01 / The missing history layer

Your tools save files. They forget the story.

Raw JSONL can tell you what happened inside one file. It cannot reliably tell you how a task moved across sessions, agents, and context resets.

resume
creates another file

The next turn looks detached from the session it continued.

fork
creates a sibling path

Experiments diverge, but most viewers flatten them into a list.

compact
folds away early turns

The summary stays visible while the original reasoning disappears from view.

Observed in one real archive

253 of 1,621 sessions

had already been removed from their original Claude Code location by the default 30-day cleanup. They survived because Swob had backed them up.

02 / Reconstruct, don't render

A truth layer above every harness.

Swob parses each platform's local history, removes transport noise, and registers the edges other viewers miss. Change agents tomorrow; keep the context you built today.

03 / What ships today

History you can use, not just store.

Swob turns scattered agent traces into a searchable working memory—without asking every team or tool to change how they work.

04 / Use the interface you already have

Swob speaks terminal.

Search, list, inspect, and resume from the CLI. Every command can return JSON, so agents can query the same history you see.

zsh · swob
$ swob search "refactor database"
$ swob list --source codex --json
$ swob resume a6771e74
$ swob insights
$ swob install # installs Agent Skill

05 / Straight answers

No launch-day sleight of hand.

The data model is ahead of the visualization. Here is exactly what you are installing today.

Roadmap

Lineage detection ships; the visual tree does not.

Today you get relationship annotations and multi-file grouping. A rendered branch graph is still being built.

Gatekeeper

The current public build is not notarized yet.

If macOS blocks it, run xattr -cr /Applications/Swob.app. Signing and notarization are in progress.

Platform

macOS only—for now.

Apple Silicon and Intel are supported. Windows and Linux builds are not available today.
