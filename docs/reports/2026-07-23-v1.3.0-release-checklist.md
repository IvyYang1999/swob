# Swob v1.3.0 发布检查单

日期：2026-07-23
适用版本：`v1.3.0`
发布责任人：yyt
定位：首个 Apache-2.0、Developer ID 正式签名版本；一次性手动信任根迁移

## 0. 不变量

- `v1.3.0` 必须手动下载安装，不能发布任何更新 metadata。
- 禁止上传 `latest-mac.yml`、`swob-signed-mac.yml` 或 `swob-canary-mac.yml`。
- 公开 tag、Release 和六个安装资产一旦发布，不重打、不替换、不复用同一版本号。
- 首次真实自动更新 E2E 是未来的 `v1.3.0 → v1.3.1`，不是 `v1.2.0 → v1.3.0`。

## 2. 创建并推送 tag

先记录准备发布的不可变 commit：

```sh
git switch master
git pull --ff-only origin master
git status --short
git rev-parse HEAD
```

确认终审通过后，由 yyt 执行：

```sh
git tag -a v1.3.0 -m "Swob v1.3.0"
node scripts/release/assert-release-version.mjs \
  --tag v1.3.0 \
  --minimum 1.3.0 \
  --stable \
  --bind-ref origin/master
git push origin v1.3.0
```

从创建 tag 起到 Release workflow 公开成功，暂停向 `master` 合入或推送
其他提交。发布门禁会在构建前和公开前各验证一次 tag commit **等于**
当时的 `origin/master` tip；任何并发推进都会安全阻断这次发布。

不要手工运行 `gh release create`。tag 会触发 `.github/workflows/release.yml`；workflow 会先构建、签名、公证和验证，再创建 draft Release，远端资产摘要复核通过后才公开。

## 5. 下载后抽样复验

在空目录下载公开资产：

```sh
release_dir="$(mktemp -d /private/tmp/swob-v130-release.XXXXXX)"
gh release download v1.3.0 \
  --repo IvyYang1999/swob \
  --dir "$release_dir"
```

复核远端资产清单与摘要：

```sh
gh release view v1.3.0 \
  --repo IvyYang1999/swob \
  --json assets > "$release_dir/assets.json"
node scripts/release/assert-release-assets.mjs \
  --inventory-json "$release_dir/assets.json" \
  --dir "$release_dir" \
  --version 1.3.0 \
  --channel swob-signed
```

- [ ] 在 Apple Silicon Mac 上挂载 arm64 DMG，拖入 `/Applications` 后可正常启动。
- [ ] `spctl` 接受安装后的应用。
- [ ] 应用版本显示 `1.3.0`。
- [ ] About/许可界面和分发包内 `LICENSE`、`NOTICE`、`THIRD_PARTY_NOTICES` 正确。

## 6. 回滚

### workflow 在 Release 公开前失败

- 不手工绕过失败步骤，不手工上传残缺资产。
- 保留 Actions 日志，修复根因后重新提交一个新 commit。
- 如果 tag 已推送，默认不移动或复用它；使用新的补丁版本发布，除非能证明 tag 从未形成任何公开 Release/资产且 yyt 明确批准删除。

### v1.3.0 已公开后发现严重问题

- 不替换 v1.3.0 的二进制，不移动 tag，不上传更新 metadata。
- 立即把 Release 改回 draft，阻止新的官方下载：

```sh
gh release edit v1.3.0 \
  --repo IvyYang1999/swob \
  --draft
```

- 在 issue/公告中说明受影响范围和手动卸载或降级方式。
- 修复后使用新版本号发布；不能让未验证的自动更新通道承担回滚。

### 仅官网或文案错误

- 安装资产和 tag 不动。
- 单独修正文案并走正常评审；本次发布不因文案修复而部署官网。

## 7. v1.3.1 留档动作

发布后保留一台专用 canary Mac 上已签名、已 stapled 的 `v1.3.0`。待 `v1.3.1` 六个签名候选资产发布后，才运行 `Promote macOS Update Channel`，完成真实检查、下载、Squirrel 安装、重启、版本与签名复验；成功后才允许上传 `swob-signed-mac.yml`。
