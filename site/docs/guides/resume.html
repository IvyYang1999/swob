04 · FEATURE GUIDE

多客户端 Resume

Resume 的承诺只到目标客户端公开支持的边界。Swob 不把“打开 App”包装成“恢复成功”。

当前行为矩阵

来源终端桌面入口诚实降级
Claude Codeclaude --resumeClaude Desktop 导入（实验开关）；Remote Control桌面入口关闭时不生成假动作
Codexcodex resumecodex://threads/<id>只允许 Codex 同源会话
Cursorcursor agent --resume无保留来源能力边界
OpenCodeopencode --session无保留来源能力边界
ZCode无公开 CLI打开 zcode:// 或工作区明确提示不能跳到指定历史会话
CC-Mirror / 其他公开 CLI 来源按各自 launcher 续接无缺 launcher 时不可伪造支持

源文件缺失时

点击 Resume 会先做可恢复性检查；确需写回时进入受控复活流程。复制 Resume 命令和 Resume Audit 不允许触发写回。

Claude Desktop 仍是实验能力

必须先在设置开启“实验：导入到 Claude Desktop”；来源不是 Claude Code 或 session ID 格式不合法时会拒绝。
