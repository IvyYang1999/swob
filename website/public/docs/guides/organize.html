04 · FEATURE GUIDE

整理与撤销

移动和重命名不是散落的文件操作，而是一笔先记反向计划、再执行的 Vault 事务。

安全整理

  1. 先预览

    项目整理与智能整理先给出目标文件夹和元数据变化。

  2. 整批提交

    每个会话包必须有正确标记，目标必须在当前 Vault 内；重名会生成安全后缀。

  3. 需要时撤销

    “撤销最近整理”只处理最近一笔 applied/partial 事务，先完整预检再反向移动。

撤销不会做什么

  • 不会覆盖后来占据原位置的内容。
  • 不会删除整理后新增的非空文件夹。
  • 不会猜测损坏日志的反向路径。
  • 每次只撤销最近一笔组织事务。
